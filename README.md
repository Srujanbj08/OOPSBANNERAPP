# OOPS Banner App

OOPS Banner App is a Java-based console application developed incrementally to demonstrate Core Java and Object-Oriented Programming (OOP) concepts through a banner printing system. Each feature branch introduces new programming concepts such as classes, arrays, loops, string manipulation, formatting, patterns, and collections while improving the banner generation process.

---

## Features

* Dynamic banner printing
* Decorative banner borders and patterns
* String formatting and alignment
* Array and loop-based rendering
* HashMap-based banner metadata management
* Modular branch-wise implementation

## Use Cases

* **UC1 – Print OOPS**
  Basic OOP structure and banner printing.

* **UC2 – Banner Print Statements**
  Multiple print statements with banner borders.

* **UC3 – Banner String Join**
  String concatenation and `String.join()` usage.

* **UC4 – Banner Array Loop**
  Dynamic banner rendering using arrays and loops.

* **UC5 – Banner Array INIT**
  Array initialization techniques and updates.

* **UC6 – Banner Pattern**
  Decorative pattern and border generation.

* **UC7 – Banner Inner**
  Text padding, alignment, and formatting.

* **UC8 – HashMap**
  Banner metadata management using `HashMap`.
